Welcome. In the next nine minutes, you will turn your laptop into a Wi-Fi security testing lab. We will install Aircrack-ng on Kali Linux and capture a handshake from your own router. This is the standard method to test your own network security. Let's begin.

First, what you need. A laptop or desktop with a Wi-Fi adapter that supports monitor mode. Most modern laptops have this built-in, but if you are using a USB adapter, check that it uses an Atheros or Realtek chipset. You need Kali Linux installed, either as a virtual machine or a dual boot. And, of course, your own Wi-Fi router. We will only test this on networks you own.

Step 1: Update your system. Open the terminal. Type: sudo apt update and press Enter. Type your password. This refreshes the software list. Next, type: sudo apt upgrade -y and press Enter. This installs the latest security patches. You will see a list of packages. Press Y to confirm. Wait for the progress bar to finish.

Step 2: Install Aircrack-ng. In the terminal, type: sudo apt install aircrack-ng and press Enter. Type Y to accept the installation. The terminal will download and install the files. When it finishes, you will see a confirmation message. The command is now ready.

Step 3: Check your Wi-Fi adapter capabilities. Type: airmon-ng check wlan0 and press Enter. Review the output. If your wireless interface appears, note its name (usually wlan0). If the interface is listed but shows no capabilities, your adapter may not support monitor mode. If you see no interfaces, verify your adapter is plugged in and recognized by the system. **Critical: If the interface does not support monitor mode, you must use a compatible USB adapter such as the Alfa AWUS036NHA before proceeding.**

Step 4: Put your adapter into monitor mode. Type: airmon-ng start wlan0 and press Enter. The terminal will respond. It will indicate monitor mode is enabled. Look at the very bottom of the output. It will create a new interface, usually called wlan0mon. This is the interface we use for scanning. **If the interface does not appear, or if the original interface does not show monitor mode support, your driver does not support this feature; you must use a compatible USB adapter.**

Step 5: Scan for networks and identify your target. Type: airodump-ng wlan0mon and press Enter. A window will open showing a list of nearby Wi-Fi networks. You will see columns for BSSID, ESSID, and PWR. **Find your router's name in the ESSID column. Note the BSSID, which looks like a string of numbers and letters. This is your router's unique address. Also note the Channel number displayed for your router.** Keep these values handy; you will need them for the next step.

Step 6: Capture the handshake. Keep the airodump-ng window running. On your computer or phone, disconnect from your Wi-Fi and reconnect. This forces a 'handshake'. **Ensure the airodump-ng window is active and look for the 'Handshake' counter in the top right to increment.** \*Tip: If the handshake does not appear immediately, verify that the correct BSSID and Channel are being monitored in the airodump window.

Step 7: Start the capture with filters. Type: airodump-ng -c [channel number] -w capture --bssid [your BSSID] wlan0mon. Replace [channel number] with the number you noted in Step 5, and [your BSSID] with the address you noted. Press Enter. The terminal will start capturing packets specifically for your router. Stay here until you see a handshake entry appear in the airodump window. It will say 'Handshake: XXXX'.

Step 8: Crack the password. Once you see the handshake, press Ctrl+C to stop the capture. The handshake data is saved in the capture file. You must have a wordlist (dictionary file) to crack the password. Type: aircrack-ng -w /path/to/your/wordlist.txt capture-01.cap and press Enter. Replace /path/to/your/wordlist.txt with the actual path to your dictionary file. The tool will analyze the handshake. If the password matches a entry in your wordlist, it will reveal it instantly. If not, you will need a different wordlist.

How to check it worked. In Step 7, you looked for 'Handshake: XXXX' in the airodump window. In Step 8, you saw the password printed on the screen. If you see the password, the process worked.

Fixes for the two most common errors. First, 'No dongles found' or interface not recognized. This means your Wi-Fi adapter does not support monitor mode. You must buy a compatible USB adapter, such as the Alfa AWUS036NHA. Second, 'Failed to crack handshake'. This happens if the password is very strong or if you did not capture a real handshake. Ensure you actually disconnected and reconnected a device to trigger the handshake. Also, ensure you are using a valid wordlist file with the aircrack-ng command.
