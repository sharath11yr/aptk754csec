Burp Suite Tutorial for Beginners

tutorial: True

Welcome. If you have ever wondered how websites handle your data or how security researchers find mistakes, you are in the right place. Right now, imagine sending a letter and being able to read it, change it, and send it back before the recipient even knows it left your hands. That is what Burp Suite does. By the end of this video, you will have Burp Suite installed, understand how it intercepts traffic, and know how to stop that first hack. Let's get started.

First, the requirements. You need a computer running Windows, macOS, or Linux. You must use a web browser—Chrome or Firefox work best. Most importantly, you need a legal target to practice on. We will use the DVWA, or Damn Vulnerable Web App, a safe, legal site designed for testing. You will also need Java installed, as Burp Suite runs on it. "If Java is not installed, please install the latest JDK from oracle.com and ensure it is added to your system PATH before proceeding." If you are on Windows, ensure you have the latest version of Windows 10 or 11. If you are on Mac, version 10.13 or newer. Linux users need version 5.10 or newer. Okay, if you have a computer, a browser, and DVWA, let's proceed.

Step 1: Install Burp Suite Community Edition. Go to the PortSwigger website and download the Community Edition. It is free. 	extbf{Important: Java must be installed and on your PATH}. If Java is not present, install it now and verify with "java -version" in your terminal or command prompt. Open the downloaded file. On Windows, click 'Next' through the installer. On Mac, drag the Burp Suite icon into your Applications folder. On Linux, the Community Edition is distributed as a Java Archive. Open your terminal, navigate to your download folder, and run: "java -jar burpsuite_community.jar". Press Enter. Accept the license agreement if prompted. Wait for the interface to load. When it says 'Done,' Burp Suite is installed.

Step 2: Launch Burp Suite. On Windows, click the Start menu and find Burp Suite. On Mac, open Applications and double-click Burp Suite. On Linux, type "burpsuite" in your terminal and press Enter (only if you have set up an alias or the symlink; otherwise use the java command from Step 1). A window will appear asking you to accept the license. Click 'I Agree'. Another window will appear asking for a proxy configuration. We will keep the default settings for now. Click OK. The main Burp Suite interface will load. You will see four tabs at the top: Target, Proxy, Spider, and Scanner. This is your control center.

Step 3: Configure your browser to use Burp as a proxy. This is the part most beginners get stuck on. We need to tell your browser to send its traffic through Burp Suite. 	extbf{For Chrome:} Open your browser's settings. Click the three dots in the top right, go to Settings, then Privacy and Security, and click 'System'. Click 'Open your computer's proxy settings'. A new window will open. Look for 'Manual proxy setup'. Turn the switch 'On'. In the 'Address' box, type 127.0.0.1. In the 'Port' box, type 8080. Click 'Save'. 	extbf{Restart your browser after saving these settings to ensure they take effect.} 	extbf{For Firefox:} Open Firefox Settings, go to General, scroll to Network Settings, and click 'Settings'. Select 'Manual proxy configuration'. Enter "127.0.0.1" in the HTTP Proxy box and "8080" in the Port box. Check 'Use this proxy server for all protocols'. Click OK. Your browser is now configured to send traffic through Burp Suite.

Step 4: Start intercepting. Ensure the 'Intercept is on' button in the top left of Burp Suite is highlighted green. If it is not, click it once to enable it. Now, open a new tab in your browser and go to the DVWA login page. The Burp Suite window will pop up. It will say 'Intercept: request'. This means Burp has grabbed the web page request. Look at the top pane. You will see 'Request' details. Look at the bottom pane. You will see the request details in text form. This is the magic moment. You have successfully intercepted traffic.

Step 5: Stop the hack. Notice the buttons at the bottom of the Intercept popup: 'Forward', 'Drop', and 'Close'. 	extbf{To stop the request:} In Burp, find the request for the login form. Click 'Drop'. Go back to your browser. Refresh the page. You will see an error or a blank screen. You just stopped the request. 	extbf{To allow the request:} If you click 'Forward', the page will load normally. Click 'Close' in Burp to clear the intercept.

How to check it worked. After clicking 'Drop' in Burp and refreshing your browser, the DVWA login page must not load or must show an error message. If the page loads normally, you either clicked 'Forward' or the intercept did not capture the request. Ensure the 'Intercept is on' button is green in Burp before loading the page in your browser for the first time.

Now, the two most common errors and how to fix them. Error one: 'Connection refused' or the proxy not working. This usually means your browser proxy settings are wrong. Go back to your browser's proxy settings. Ensure the Address is exactly 127.0.0.1 and the Port is exactly 8080. If you used a different port, change it here. Also, ensure you have restarted your browser after configuring the proxy. Error two: Intercept is not turning on. If you click the green button and it does not stay green, ensure no other program is using port 8080. Close other browser tabs or restart your computer. If that fails, right-click the Intercept button and select 'Options'. Ensure 'Intercept client requests' is checked.

You now have Burp Suite installed, configured your browser, intercepted your first request, and stopped a hack using the 'Drop' function. This is the foundation of web security testing. Remember, always use these skills on your own lab or with explicit permission. The best way to learn is to practice.
