[STEP 1: UNDERSTANDING THE TARGET]

Before we type a single command, we have to understand what we are up against. Your Wi-Fi router uses a security protocol called WPA2. This is the standard for almost every home and office network. The way WPA2 works is through a 'Four-Way Handshake.' When you type your password into your laptop to connect, your device and the router perform a secret dance. They prove to each other that they both know the password, without actually sending the password over the air. This handshake generates a unique encryption key for your session.

The mistake many people make is thinking they can just run Aircrack-ng and it spits out the password instantly. That is not how it works. Aircrack-ng is not a magic wand; it is a pair of scissors. It cuts the encrypted traffic to find the 'Handshake' packet. Once it has that packet, it uses a process called a 'Dictionary Attack' or a 'Brute Force Attack' to guess the password. If your password is '12345678', it will be cracked in seconds. If it is a random string of 20 characters, it might take a supercomputer years. The tool itself does not break the encryption; it just collects the data needed for the guesses to work.

[STEP 2: THE SETUP - GETTING AIRCRACK-NG READY]

To follow along, you need a laptop running Linux, or Linux installed via a virtual machine. Windows users will need to install a subsystem called WSL. Once you have Linux up and running, open your terminal.

First, we need to verify our wireless card supports Monitor Mode. This is the mode that allows your card to listen to all traffic in the air, not just the traffic sent to your specific device. Not all Wi-Fi cards support this. If you are buying a new card for this purpose, look for one with the chipset 'Atheros' or 'Realtek RTL8812AU.'

Now, let's check if our card is ready. Type this command:

"iwconfig"

Look for your wireless interface, usually named 'wlan0'. If you see 'Mode:Monitor', your card already supports it, but it is likely disabled. If you do not see Monitor Mode, you must install compatible drivers or use a card that supports it natively. **Crucially, you must activate Monitor Mode before proceeding.**

Next, we need to put the card into Monitor Mode. This is done with the 'airmon-ng' command. Type:

"sudo airmon-ng start wlan0"

You will see output indicating that monitor mode is enabled on 'wlan0mon'. This new virtual interface, 'wlan0mon', is what we will use for the scanning and capturing. It essentially tells the card: 'Listen to everything happening in the 2.4GHz or 5GHz frequency, regardless of who it is for.'

[STEP 3: SCANNING FOR NETWORKS]

Now that our card is listening in Monitor Mode, we need to find the network we want to test. We will use 'airodump-ng'. This command creates a visual map of the airwaves.

Type:

"airodump-ng wlan0mon"

Your screen will flood with data. You will see columns for BSSID (the router's MAC address), PWR (signal strength), Beacons, #Data, CH (Channel), and ENCRIPTION.

Look for your target network. **It is crucial to note the Channel number immediately.** We will lock onto this channel in the next step to prevent capture failure. Note the BSSID as well. For this demonstration, let's assume your target is on Channel 6 and the BSSID is 'AA:BB:CC:DD:EE:FF'.

[STEP 4: CAPTURING THE HANDSHAKE]

This is the core of the process. We want to force the router to perform the Four-Way Handshake so we can capture it. Normally, the handshake happens when a new device connects. But we can speed this up.

We will use a deauthentication attack. This sends a fake disconnection message to every device currently connected to the Wi-Fi. Their laptops and phones will instantly pop up a window asking 'Enter Wi-Fi password to reconnect.' When they type it, the router performs the handshake, and we catch it.

Type the following command to start capturing packets on our specific channel and target BSSID:

"airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon"

The '-c 6' locks us to channel 6. '--bssid' tells the tool to only look at that specific router. '-w capture' names the output file 'capture'.

Now, open a new terminal tab and type:

"aireplay-ng -0 10 -a AA:BB:CC:DD:EE:FF wlan0mon"

The '-0' means deauthentication. The '10' means we are going to send 10 deauth packets. '-a' is the target router's address. This command effectively yells 'Disconnect!' to all connected devices. **Watch the airodump-ng terminal, not the aireplay-ng terminal.** You will see devices reconnecting. As soon as you see the 'Handshake' appear in the top right corner of the airodump-ng screen, type 'q' or press Ctrl+C in the aireplay-ng terminal to stop the attack. We have now captured the handshake. This file contains the encrypted proof that the password was used, but not the password itself.

[COMMON MISTAKES AND MYTHS]

One of the biggest myths is that Aircrack-ng works on WPA3. It does not. WPA3 is the new standard, and it fixes this specific handshake vulnerability. If you have a modern router, check if WPA3 is enabled. If you are still on WPA2, you are potentially vulnerable.

Another mistake is ignoring the channel locking. Some wireless cards will automatically switch channels to find a signal. If your capture file is empty, it might be because your card hopped away from the target's channel. **Always use the '-c' flag to lock onto the specific channel, as demonstrated in Step 4.**

A pro tip: Always update your router's firmware. Manufacturers release patches that can mitigate these types of attacks. Also, disable WPS (Wi-Fi Protected Setup) on your router. WPS is a separate vulnerability that allows attackers to bypass the password entirely using a PIN brute-force.

[DEFENSE SECTION]

How do you stop this? First, upgrade to WPA3 if your router supports it. WPA3 uses a new handshake called 'SAE' (Simultaneous Authentication of Equals) which is resistant to offline dictionary attacks.

If you cannot upgrade, ensure your Wi-Fi password is long and random. A minimum of 16 characters, mixing numbers, symbols, and upper and lower case letters, is recommended. Avoid dictionary words.

Second, turn off WPS. This is usually a setting in your router's admin page under 'Wireless' or 'Security'.

Third, monitor your connected devices. If you see a device you don't recognize, disconnect it immediately.
